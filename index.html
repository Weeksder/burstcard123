Toolbar Buttons

⚙️ Manage My Decks

📖 About this page

This page is your personal deck library — a collection of JSON flashcard sets you can load instantly from the side panel without having to re-import each time.

Use Add a new deck to import a JSON file. Once added, it appears in the side panel where you can load, add to, or remove from your active deck with a single tap.

You can organise units into Groups by creating a group and dragging units into it. Groups keep your library tidy when you have many files.

📁 Your JSON files are cached directly in your browser's storage — no internet connection needed to reload them after the first import.
