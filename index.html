Toolbar Buttons
Add — Create a new flashcard with an image and word. Shuffle — Randomly reorder your cards. Delete — Remove the current card from the deck. Clear — Delete all cards in the current deck. Rename — Edit the word on the current card. Games — Open the game menu to play with your cards. Load — Load a saved JSON deck file. Manage — Open your saved deck library to quickly load or switch decks. More — Access Load, Save, Rename All, and Clear All options. Settings — Clip images, resize text, preview cards, toggle sound and display options.

Look at the letter at the top. Tap every bubble that matches it.

📚 Deck Library

📖 How this library works

1. Import — Pick one or more JSON decks, then tap Next.

2. Organize — Browse all saved decks; rename or delete in Edit. Use Create to keep it in the default list, or Group for a folder.

3. Folders — Create folders and assign decks. Load decks from the side panel anytime.

💡 Importing does not automatically load the deck into play — use the side panel for that.
